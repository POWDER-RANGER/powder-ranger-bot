Aether

A local, accessibility-first game companion. The player directs; the companion plays through a virtual controller, from the screen alone.

Principle

The player is the legend; the companion is the body double. Every controller output traces to a player intent or a delegation the player granted, and the player can take control back at any instant.

How it works

  • One process, the Governor, owns the virtual controller. Everything else sends signed intent packets to it.
  • Output is held to human limits: reaction time, smooth travel, tremor, button timing, press-rate caps.
  • No game memory access, no code injection. The game sees only a controller.
  • Play mode runs offline. Every decision is written to a hash-chained, sealed log.
  • The player's channels (pad, keyboard or switches, voice, gaze) merge through shared control.

Status

Stage 1 is code complete and unit-tested. The first end-to-end hardware run has not happened yet; the repository states what has and has not been verified.
