01 · Briefing

One principle

The player is the legend. PR-REX is the body double.

The player directs

Every controller output traces to a player intent or to a delegation the player granted. No grant, no output.

Control returns at once

Player input outranks the companion on every tick. There is no mode to escape from and no menu to find.

A body, not a backdoor

The companion sees the screen and presses a virtual controller. It never reads game memory, injects code, or moves faster than a human can.

Local by default

Play mode is offline. Inputs, voice and gaze never leave the machine. The network is for prep, to fetch models.

03 · Rules of engagement

What the Governor enforces

  1. Kill switch latches the halt, revokes every delegation, then writes neutral. Resume needs a new grant.
  2. Stale, replayed and out-of-order packets are dropped.
  3. Player input always passes and pre-empts the companion.
  4. Companion output needs an active delegation, limited to the game pack's scopes.
  5. Online mode: no full autopilot, and the player must be present.
  6. Companion output only while the game window is in front.
  7. Confidence floor, per-source rate limit, menu buttons stripped.
  8. Watchdog: no output played for 500 ms eases the pad to neutral.
  9. Shutdown and faults leave the pad neutral. The log is sealed on close.
  10. No game memory access, no code injection. The game sees a controller.

05 · Roadmap

Only stage 1 is committed

STAGE 1 · NOW

Smoke test

SuperTuxKart, offline. The companion drives a lap and the report is read end to end.

Gate (proposed): a clean lap, latency numbers in the report.
STAGE 2

Measure and tune

NitroGen latency and play quality without pausing the game. Fit the player's motor profile.

Gate (proposed): a full race with no player input.
STAGE 3

Shared control

Gaze, voice and pad working at once. More game packs.

Gate (proposed): a real player finishes a session on their own terms.
STAGE 4

Planner

Spoken orders become intents the Governor still approves.

Gates follow the data.

Stages are not to scale and carry no dates. The smoke-test data decides whether the later gates hold.
