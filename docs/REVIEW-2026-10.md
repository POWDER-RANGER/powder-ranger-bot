# Code review, October 2026

Scope: full read of the codebase at commit `c985d2b`, reproduction of the
suspected defects in simulation, and a comparison with published systems.
Status below is as of the commit that adds this file.

| ID | Severity | Finding | Status |
| --- | --- | --- | --- |
| F1 | High | A per-packet reaction delay plus a queue clear on every packet erased overlapping chunks. At the default profile, packets arriving faster than about 400 ms mostly never played (share of packets that played at least one frame: 0% at 50-100 ms, 16% at 150 ms, 51% at 200 ms, 79% at 250 ms, 99% at 400 ms). | Fixed: one reaction delay per episode; newer chunks supersede older frames. Regressions in `tests/test_review_regressions.py`. |
| F2 | High | A held stick stayed at its old value while newer packets were discarded; the watchdog counted packet arrival, so it stayed silent. | Fixed: watchdog watches played output; stale holds resolve to the newest command. |
| F3 | Medium | A validly signed but malformed packet (missing field, unknown button) crashed the Governor; NaN passed the stick clamp. | Fixed: rejected, counted, logged; non-finite values and oversized chunks refused. |
| F4 | Medium | NitroGen server binds all interfaces and unpickles requests; firewall script was manual. | Mitigated: start script refuses without its firewall rule. Upstream behavior unchanged. |
| F5 | Medium | A delegation's scope was only a label; voice grants ignored the pack's allowed scopes. | Fixed: Governor refuses grants outside the pack's scopes. |
| F6 | Medium | Kill path wrote neutral before latching the halt, leaving a short window. | Fixed: halt latches first. |
| F7 | Medium | STOP file path was relative to the working directory. | Fixed: absolute, `~/.powder_ranger/STOP`. |
| F8 | Medium | Spoken grants have no confirmation. | Open, deliberately: waiting for hardware data. |
| F9 | Low | Capture region fixed at start. | Open. |
| F10 | Low | Image downscale uses PIL BOX; NitroGen's own client uses OpenCV INTER_AREA. | Open; measure effect on the first run. |
| F11 | Low | Grant/resume messages can be replayed within a session; session key lives in an environment variable. | Open. |
| F12 | Info | Test gaps, no CI, unpinned dependencies, lint findings. | Fixed: CI, lower bounds, ruff clean. |
| F13 | Info | ViGEmBus is retired upstream. | Open; no maintained drop-in found. |

Also open by choice: launcher heartbeat to the Governor, per-control claims for
the physical pad.

Prior art compared: GamePals (command interpreter and arbitrator over a
virtual controller), SIMA 2, Lumine, Game-TARS, Xbox Controller Assist, Gaming
Copilot, shared-autonomy research, and Simplex-style runtime assurance. None
combines a signed single-path governor, human-limit output, sealed audit and
fully local play.
